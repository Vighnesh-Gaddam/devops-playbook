# PHASE 1: Cloud Computing Fundamentals

## Week 1 – Unit 1: Introduction to Cloud Computing

### 1.1 Introduction
- What is Cloud Computing?
- Definition and basic concepts.
- History and evolution of Cloud Computing.
- Traditional Computing vs Cloud Computing.
- Distributed Computing.
- Grid Computing.
- Utility Computing.
- How Cloud Computing works.

### 1.2 Characteristics
Learn the five essential characteristics:
- On-demand self-service.
- Broad network access.
- Resource pooling.
- Rapid elasticity.
- Measured service.

### 1.3 Advantages and Disadvantages
- Cost reduction.
- Scalability.
- Flexibility.
- Availability.
- Data security concerns.
- Internet dependency.
- Vendor dependency.

### 1.4 Cloud Service Models

Study these in depth:

| Model | Meaning | Example |
|---|---|---|
| IaaS | Infrastructure as a Service | AWS EC2 |
| PaaS | Platform as a Service | Google App Engine |
| SaaS | Software as a Service | Gmail |

Learn:
- Definition of each model.
- Architecture.
- Advantages and disadvantages.
- Real-world examples.
- Responsibility of cloud provider vs customer.
- Differences between IaaS, PaaS and SaaS.
- Desktop as a Service (DaaS).
- Function as a Service (FaaS).

### 1.5 Cloud Deployment Models
- Public Cloud.
- Private Cloud.
- Hybrid Cloud.
- Community Cloud.

For each, learn:
- Definition.
- Architecture.
- Advantages and disadvantages.
- Real-world examples.

### Practice Questions

2. Explain the evolution of Cloud Computing.
3. Explain IaaS, PaaS and SaaS with examples.

# 3. Daily Study Routine

For 2–3 hours daily:

| Duration | Activity |
|---|---|
| 45 min | Watch lecture / understand concepts |
| 35 min | Read textbook or reference notes |
| 30 min | Prepare handwritten or digital notes |
| 20 min | Practice diagrams and comparisons |
| 20 min | Solve questions without looking at notes |
| 10 min | Revise yesterday's topics |

## Notes Format

Follow this structure for every topic:

1. 📌 Definition – What is it?
2. ⭐ Why? – Why is it required?
3. 📝 Working – How does it work?
4. 📂 Architecture/Diagram – Draw its architecture.
5. ⚠️ Advantages and Disadvantages.
6. 🎯 Real-world Examples.
7. 🧠 Interview and Exam Questions.
